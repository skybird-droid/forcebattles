# Force Battles

## Updates panel
Whenever you make a change players would notice (new or changed characters, abilities, balance, rules, UI, features), add it to the `UPDATES` list in `js/updates.js` in the same task:
- Changes made on the same day go into that day's entry at the top. Otherwise add a new entry at the top with today's date and a short title.
- Write one short, player-friendly line per change. Don't mention code or file names.
- Skip pure bug fixes or refactors that players can't see, unless they fix something players would have noticed.
